# Huduma Smart

## Overview
Huduma Smart is a web-based AI automation agent designed to streamline interactions with the Higher Education Financing (HEF) and Higher Education Loans Board (HELB) portals. Built utilizing **n8n** for workflow orchestration and **Playwright** for headless browser automation, this project automates repetitive tasks such as portal logins, payload mapping, and data retrieval.

## Features
* **Portal Automation**: Navigates the HEF/HEB portal securely using Playwright.
* **Workflow Orchestration**: Utilizes n8n to manage automation sequences and handle complex data payloads.
* **Headless Execution**: Capable of running efficiently in background environments.

## Prerequisites
Ensure the following are installed on your system (developed and tested on Fedora Linux):
* Node.js and npm
* n8n
* Playwright
